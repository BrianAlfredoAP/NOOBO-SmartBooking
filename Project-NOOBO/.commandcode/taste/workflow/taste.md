# Workflow Preferences

- Wants work committed and pushed when a task/feature set is finished ("kalau sudah jangan lupa commit dan push"). Confidence: 0.85
- Prefers one commit per completed feature rather than a single large commit at the end. Confidence: 0.8
- Wants the existing tests actually run and reported (e.g. backend `npm test`) before moving on to the next step of work ("test dulu … sebelum kita lanjut"). Confidence: 0.6
- Expects the latest `main` pulled (and prior analysis re-run against it) before starting new work, so findings aren't based on stale code. Confidence: 0.7
